# BPL & BASS: Visual Navigation Runtime

This directory contains the online navigation side of the project:

- `bass.py`: belief propagation localization (BPL), belief-aware subgoal search
  (BASS), and a ROS global planner node.
- `local_planner.py`: a ROS local planner node that consumes subgoal images and
  publishes local waypoints through a learned navigation model.

The ROS nodes require additional runtime packages and project-specific model
code. For ROS-free localization/planning tests, use the stable `ulvn_core`
package from the repository root.

## Architecture

```text
Camera image topic
      |
      v
  bass.py
  - VPR encoding
  - BPL belief update
  - BASS path planning
  - dynamic subgoal selection
      |
      | publishes /goal_path
      v
  local_planner.py
  - consumes current observation and subgoal image
  - runs learned trajectory/action model
  - publishes /waypoint and RViz markers
```

## Inputs

`bass.py` requires graph artifacts whose node order is aligned:

- `--descriptors_path`: NumPy array `[N, D]` with node descriptors.
- `--adjacency_matrix_path`: NumPy array `[N, N]` with graph edges.
- `--image_paths_file`: text file with one image path per node.
- `--img_dir`: base directory for relative paths in `image_paths_file`.

These files can be generated by the RAVEL pipeline. See `../docs/DATA_FORMATS.md`.

## Conda environment

From the repository root:

```bash
conda env create -f environment-navigation.yml
conda activate ulvn_nav
```

ROS packages must be installed through your ROS distribution:

- `rospy`
- `sensor_msgs`
- `std_msgs`
- `visualization_msgs`

The local planner uses the included `inference_utils` package with ViNT and
NoMaD wrappers. Runtime still requires Torch, Diffusers, EfficientNet,
checkpoint files, and ROS Python packages.

## Configuration

Create local config files from the examples:

```bash
cp ../config/robot.example.yaml ../config/robot.yaml
cp ../config/models.example.yaml ../config/models.yaml
```

Then edit them for your robot and model checkpoints.

`robot.yaml` must contain at least:

```yaml
max_v: 0.3
max_w: 0.4
frame_rate: 4
```

`models.yaml` is loaded by `inference_utils.common.load_config()` and must match
the selected model architecture. The included `MODEL_REGISTRY` exposes `nomad`
and `vint`; `config/models.example.yaml` provides public keys `nomad_ulvn`,
`vint_ulvn`, plus short aliases `nomad` and `vint`.

The included per-checkpoint configs define the ULVN local-planner models:

- `../config/model_configs/nomad_ulvn.yaml` for the NoMaD ULVN checkpoint.
- `../config/model_configs/vint_ulvn.yaml` for the ViNT ULVN checkpoint.

Checkpoint files are intentionally not tracked in Git. Place released weights
under `../checkpoints/local_planner/` or edit `ckpt_path` in `models.yaml`.

## Run the global planner

From the repository root:

```bash
python "BPL & BASS/bass.py" \
  --img_dir data/landmark \
  --descriptors_path continuous_images/global-feats-test.npy \
  --adjacency_matrix_path continuous_images/adjacency_matrix.npy \
  --image_paths_file continuous_images/image_paths.txt \
  --goal_image_index 0 \
  --arch megaloc \
  --image_topic /isaac_node/camera0/image_raw
```

Important runtime notes:

- `--arch megaloc` loads MegaLoc through `torch.hub`.
- `--arch resnet18`, `--arch resnet50`, and `--arch dinov2_vits14` reuse encoder
  definitions from `RAVEL/scripts/encode_images.py`.
- The first camera frame is used for initial localization.
- The selected subgoal image path is published on `/goal_path`.

## Run the local planner

From the repository root, after ROS, configs, and model checkpoints are
available:

```bash
python "BPL & BASS/local_planner.py" \
  --model nomad_ulvn \
  --config config/models.yaml \
  --robot-config config/robot.yaml \
  --num-samples 8 \
  --waypoint 3 \
  --image-topic /isaac_node/camera0/image_raw \
  --goal-path-topic /goal_path \
  --waypoint-topic /waypoint
```

## Launch the online stack

`launch_ulvn.sh` starts `bass.py` and `local_planner.py` in one tmux session.
Install `tmux` on the robot/simulator machine before using it.

```bash
cd "BPL & BASS"

ULVN_CONDA_ENV=ulvn_nav bash launch_ulvn.sh \
  --bass \
    --img_dir ../data/ulvn_sim/images/taoyuan1 \
    --descriptors_path ../data/ulvn_sim/features/data_features1.npy \
    --adjacency_matrix_path ../data/ulvn_sim/adjacency_matrix/adjacency_matrix_directional.npy \
    --image_paths_file ../data/ulvn_sim/images/taoyuan1_paths.txt \
    --goal_image_index 239 \
    --image_topic /isaac_node/camera0/image_raw \
  --nav \
    --image-topic /isaac_node/camera0/image_raw \
    --goal-path-topic /goal_path \
    --model nomad_ulvn \
    --config ../config/models.yaml \
    --robot-config ../config/robot.yaml \
    --num-samples 8 \
    --waypoint 3
```

Before launching, make sure ROS is sourced, `config/models.yaml` points to the
released checkpoint files, and `config/robot.yaml` matches the robot or
simulator velocity limits.

## ROS topics

Published by `bass.py`:

- `/goal_path` (`std_msgs/String`): current subgoal image path.
- `/topoplan/reached_goal` (`std_msgs/Bool`): goal reached flag.

Published by `local_planner.py`:

- `/waypoint` (`std_msgs/Float32MultiArray`): selected local waypoint.
- `/goal_image1` (`sensor_msgs/Image`): subgoal image visualization.
- `/path` (`visualization_msgs/Marker`): sampled trajectory visualization.
- `/sampled_actions` (`std_msgs/Float32MultiArray`): sampled action sequence.

Topic names for the local planner can be overridden through CLI arguments.

## ROS-free public API

```python
import numpy as np
from ulvn_core import BeliefAwareSubgoalSearch, PlaceRecognition, load_topomap

topomap = load_topomap(
    "outputs/example_topomap/work/data_features.npy",
    "outputs/example_topomap/results/pruned_adjacency_matrix.npy",
    "outputs/example_topomap/work/data_paths.txt",
)

bass = BeliefAwareSubgoalSearch(topomap.adjacency_matrix, topomap.descriptors)
localizer = PlaceRecognition(topomap.descriptors, topomap.adjacency_matrix)

goal_idx, start_idx = bass.initial_localize(
    topomap.descriptors[20],
    topomap.descriptors[0],
)
path = bass.plan_path(start_idx, goal_idx)
subgoal = bass.next_subgoal(current_idx=start_idx, n_ahead=2)
```

For a command-line version of the same flow, run
`python scripts/offline_navigation_demo.py` from the repository root.

## Operational requirements

- Source ROS before launching the online stack.
- Place ViNT/NoMaD checkpoints under `../checkpoints/local_planner/` or update
  `../config/models.yaml`.
- Quote the `BPL & BASS` path in shell commands because the directory name
  contains spaces.
